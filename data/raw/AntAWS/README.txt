AntAWS data for PolarGrid AI
==============================

Use the 3-hourly AntAWS CSV files for Antarctic weather validation.

Project location:
data/raw/AntAWS/

Recommended:
- Keep the original station filenames.
- Do not mix these files with NCPOR Maitri AWS data.
- Use AntAWS mainly for independent Antarctic-wide weather validation.
- Keep the original raw data unchanged.

The folder contains the 3-hourly station files from the supplied AntAWS dataset.
